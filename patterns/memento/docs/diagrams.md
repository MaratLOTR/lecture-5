# Схемы: Memento — Снимок (самостоятельно)

[Связи классов](classes.svg) и [последовательность вызовов](sequence.svg) доступны без интернета.
На схеме последовательности строки идут сверху вниз. Результаты указаны у вызовов.
[Исходник PlantUML](memento_uml.puml) соответствует ролям паттерна из лекции.
Схемы показывают готовый пример, расширения заданий в них не включены.

[Шпаргалка](cheatsheet.html) содержит теорию, актуальный код и проверки.
