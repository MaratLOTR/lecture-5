# Задание: предупреждение о перегреве

В sensor.py добавьте HeatWarning. В __init__ создайте warnings = [].
update(value) добавляет значение в warnings, только если value >= 28.
Подпишите объект дважды и передайте 27, 28, 28, 29: ожидается [28, 29].
Отпишите его и передайте 30: список не должен измениться.
Не меняйте TemperatureSensor и тесты.

## Дополнительная практика

observer_once.py: OneShotObserver сохраняет одно значение в values и отписывается
через sensor.unsubscribe(self). Остальные подписчики получают текущее событие.
Проверьте tests/test_extra.py.

```bash
python3 -m pytest tests/test_task.py
```
