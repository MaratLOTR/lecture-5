Strategy — Стратегия

Термостат хранит стратегию HeatingStrategy и делегирует ей power(current, target). HeatingStrategy — абстрактный класс ABC с abstractmethod. Eco и Comfort наследуют его. Eco возвращает 40%, когда температура ниже цели, иначе 0%. Comfort возвращает разницу температур, умноженную на 30, с ограничением от 0 до 100%. set_strategy() меняет алгоритм у существующего Thermostat. При 19 и 22 °C результаты: 40 и 90%.

Роли: Thermostat — Context, HeatingStrategy — Strategy, Eco/Comfort — ConcreteStrategy, код демонстрации — Client. Контекст работает через общий интерфейс и не перечисляет конкретные алгоритмы. Стратегии нужны для независимого изменения алгоритмов. Для двух стабильных веток обычная функция с if может быть проще. Алгоритмы учебные и не являются физической моделью отопления.

heating.py
"""Strategy: смена алгоритма отопления у существующего термостата."""

from abc import ABC, abstractmethod

class HeatingStrategy(ABC):
    @abstractmethod
    def power(self, current, target):
        pass

class Eco(HeatingStrategy):
    def power(self, current, target):
        return 40 if current < target else 0

class Comfort(HeatingStrategy):
    def power(self, current, target):
        return min(100, max(
            0, (target - current) * 30
        ))

class Thermostat:
    def __init__(self, strategy: HeatingStrategy):
        self.strategy = strategy

    def set_strategy(self, strategy):
        self.strategy = strategy

    def tick(self, current, target):
        return self.strategy.power(
            current, target
        )

tests/test_example.py
import unittest
from ..heating import HeatingStrategy, Eco, Comfort, Thermostat


class StrategyTests(unittest.TestCase):
    def test_abstract_contract_cannot_be_instantiated(self):
        with self.assertRaises(TypeError):
            HeatingStrategy()

    def test_runtime_replacement_preserves_context(self):
        context = Thermostat(Eco())
        self.assertEqual(context.tick(19, 22), 40)
        chosen = Comfort()
        context.set_strategy(chosen)
        self.assertIs(context.strategy, chosen)
        self.assertEqual(context.tick(19, 22), 90)

    def test_power_boundaries(self):
        for strategy in (Eco(), Comfort()):
            for current in (22, 23):
                self.assertEqual(strategy.power(current, 22), 0)
        self.assertEqual(Comfort().power(-10, 22), 100)
        self.assertEqual(Comfort().power(21, 22), 30)
